# 存款转 ETF：实验包（34 个实验，统一 10,000 户）

本包把《存款转 ETF：什么因素真的有效？》（2026-10-29 扰动因素分析报告）里出现的全部实验
重新组织成可直接运行的实验文件夹：**同一批 10,000 户、同一套五维补全、每个实验一个文件夹**。

- 全部实验用**同一批 10,000 户画像**（`共享/画像池_10000户.jsonl`），因此不同实验之间可以直接按户配对。
- 画像的五维补全用**此前的方式**（2026-10-28 定稿的补全提示词、schema 与校验器），覆盖全部 10,000 户、每户 5 套。
- 每个实验文件夹里都写明**用的是哪一套画像**、题面要素、调用量与分析口径。

## 二、每个实验文件夹里有什么

## 四、口径上必须注意的三件事

**一、户数全部统一成 10,000，不能再拿报告里的 91 / 257 / 776 户数字直接对照。**
报告里那些数字是在子群上算的；本包全部实验都在 10,000 户上跑，子群结论需要在同一批结果里按
`historical_deposit_group` 等字段重新切分后计算。相应字段已在画像池中保留（`asset_bracket`、`risk_preference`、
`stratum_id`），但历史子群的成员名单需要用新增的基线结果重新冻结，不能沿用旧名单。

**二、输出格式本身是很大的效应，必须分开跑、分开报。**
编号 15 与 16 是同一条件、只差输出格式（菜单编号 vs 六键金额），这是报告 5.4 节指出的最大一处伪影，
因此两者都保留为独立实验。

**三、五维补全是合成设定，不是真实观测。**
补全块在题面里以「补充投资画像：」的形式出现，与原 36 字段画像分开；分析时任何"补全导致份额变化"的结论
都必须注明这是合成画像的效应，报告 5.1 节已说明这类结果不可对外。

## 五、复现

```bash
cd _构建
python3 extract_shared.py          # 共享层：画像池 / 人物文本 / 产品条款 / X 映射
python3 extract_v3_templates.py    # 原版十五条件题面
```

```bash
cd 共享/五维补全
python3 prepare_inputs.py          # 冻结 50,000 条补全请求

```
