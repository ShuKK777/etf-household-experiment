# 设计文档

本目录记录**每一轮实验怎么设计**：改了哪个变量、和谁比较、识别的是什么。
结果不在这里（结果在 `results/`，解读在 `报告/实验汇总.md`），因为逐户数据有数百 MB，
不可能全部入库，而设计的文字只有几十 KB——这一层应当完整、可追溯。

## 各轮之间的分工

**① 十五条件是主实验。** 一个基准加十四个单条款偏离，全部逐户配对，回答
"改一条条款，概率移动多少"。其余五轮都在补它的漏洞：

- **② 因子设计**补的是"单条款相加是否等于联合效应"。①里每条条款单独呈现，
  读者会以为效应可以线性叠加；162 格全交叉才能检验交互项。
- **③ 两拍闭环**补的是"书面条款 vs 已实现状态"。①里条款只是写出来，真实客户是先买后被告知。
- **④ 句子安慰剂**补的是③的可比性。③追加的那句话同时改变了内容、长度和复述，
  没有对照臂就不知道效应来自哪一项。
- **⑤ 文本探针**补的是"效应是不是措辞造成的"。同一条款换个说法、换个选项顺序，
  概率就动，所以必须先把呈现噪声的量级测出来。
- **⑥ 34 实验包**是另一条线：把此前散落在多份报告里的实验统一到同一批户、同一套补全，
  让它们之间可以互相配对。

## 读这些文档时要注意的三条口径

**1. 户数统一是 10,000。** 早期报告里的 91 / 257 / 776 户是子群数字，不能与本批直接对照。

**2. 五维补全是合成设定，不是观测。** ⑥ 的画像在原始 36 字段之外追加了一个五字段块
（成年后非存款投资年限、历史投资品类、本笔资金用途、用款期限、现金覆盖）。
这个块在题面里单列，任何"补全导致份额变化"的结论只能当合成画像的效应。

**3. 输出格式本身是大效应。** ⑥ 里编号输出（`Pxx`）与六键金额输出是同一条件的两个独立实验，
必须分开跑、分开报，不能合并。

世界状态。**但报告里必须标明它们是不同的执行路径。**
