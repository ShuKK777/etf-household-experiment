# 句子安慰剂：设计说明

## 一、这个实验要回答什么

两拍闭环要求模型读完"上一轮选择未成交"这句话之后重新选择。但那样的一句追加文字
同时包含三样东西：**内容**（没买成）、**长度**（多了一句）、**复述**（重复了你的选择）。
主实验无法区分这三者，所以这里做一个两臂对照，只把**内容**隔离出来。

问题是：**"写明没买成"本身是否改变选择？** 如果改变了，是往哪个方向？

## 二、样本与随机化

- 对象：#6（起购 10,000 元）下 b1 与 b2 的全部 **5,600 户**——这些户的闲置资金
  1,500 元或 9,100 元，都够不到 10,000 元门槛。
- 随机对半：每档内按 `sample_index` 排序后用种子 `20261026` 做置换，前一半进
  "真句"臂，后一半进"对照句"臂。b1 的 3,000 户分 1,500 / 1,500，b2 的 2,600 户分 1,300 / 1,300。
- 两臂户数相同，随机化脚本断言总数恰为 5,600。

## 三、两臂的句子

**真句**（按户的资产档填金额）：

> 上一轮选择未成交：所选产品净申购金额至少 10,000 元，现有 {金额} 元不足，资金未动，目前没有持有该产品。

**对照句**：

> 上一轮选择已保存：系统已记下本次勾选，页面维持原来样子，记录没有其他改动，请继续查看当前页面即可，本次记录只作留存。

### 两句为什么可比

对照句是专门构造的，有三条硬约束，构建脚本里都有断言：

1. **字符数完全相同**。`build_placebo_c06.py` 断言
   `len(真句) == len(对照句)`，且把金额换成 9,100 之后长度也仍相等。
   所以长度效应在两臂之间抵消。
2. **不含任何关键词**。对照句不得出现"未成交、没买成、门槛、10,000、10000、不足、
   起购、资金、余额、持有、产品、元"中的任何一个词。
3. **同样的复述结构**。"上一轮选择已保存"与"上一轮选择未成交"都以"上一轮选择已…"开头，
   复述效应也抵消。

因此两臂唯一的差别是**内容**：一个是"没买成"，一个是"记下了但什么都没变"。

## 四、运行

| 项 | 设置 |
|---|---|
| 模型 | `sharp-322m`、`sharp-4b` |
| 调用 | 一户一次同步 `/v1/systemone`，八个通道并行 |
| 条数 | 5,600 户 × 2 臂 × 2 模型 = 22,400 |
| 题面 | 与 #6 第一拍完全相同，只在「当前事件」末尾追加一句 |
| 打分 | 与主实验同一检查点、同一推理设置、同一选项顺序 |

## 五、估计口径

对每户算第二拍减第一拍的差，再按该户的 `normalized_weight` 加权平均。
区间用家庭聚类 bootstrap（B=1,000，种子 `20261021`），同一户只出现一次。

主指标是 `p_C+p_D+p_E+p_F`（纯债与三只 ETF 的概率合计）和 `p_A`（存款）。

另报一条**两臂之差**：真句臂的平均变化减对照句臂的平均变化，两臂各自独立重抽。
这条差值是"内容"的净效应，也是这个实验唯一想下的结论。

## 七、这个设计的一个已知局限

两臂都只覆盖 #6 这一题。门槛是"买不到"最典型的情形，但锁定、锁定费这类条款的
"状态化"是否也遵循同样的确认效应，本实验无法回答。要推广需要每一题各自配一个对照臂。
