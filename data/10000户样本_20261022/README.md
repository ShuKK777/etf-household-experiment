# 10,000 户样本

直接使用 [家庭数据.jsonl](家庭数据.jsonl)，每行一户，全部 15 个条件共用。

每户包含：

- 完整 36 字段画像：profile。
- 闲置资金（元）：assigned_idle_X_cny。
- 分析权重：normalized_weight。
- 固定选项顺序：display_order。
- 运行批次：batch，1 为首批 3,000 户，2 为其余 7,000 户。
- 固定家庭编号及源数据行号。

样本共 10,000 户，无重复，模型尚未运行。资产五档人数为 3,000、2,600、2,400、1,200、800。

编码版、Parquet 文件、抽样脚本和核对记录统一放在“抽样记录”中，需要时查看 [详细说明](抽样记录/详细说明.md)。
