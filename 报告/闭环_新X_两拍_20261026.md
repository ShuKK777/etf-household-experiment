# 主实验：同一道题的两拍结果回写（新 X）

这是一项主实验。它回答的是：同一张菜单，在世界把上一轮成交结果写回状态之后，选择概率怎么改。

一万户、十五条条款的无记忆比较继续使用已经完成的八组结果。那些表回答“改一条条款，概率移动多少”。本实验只做新 X 的第 4、6、8 题，第二拍的结果只回到同一道题，不带进其他条款。

## 一 为什么用新 X，为什么用满一万户

新 X 的闲置资金是 b1 1,500、b2 9,100、b3 30,000、b4 53,000、b5 88,000 元。起购 10,000 元时，b1 和 b2 都买不了纯债基金和三只 ETF，共 5,600 户。b2 的 9,100 元离门槛只有 900 元。老 X 里只有 b1 的 2,500 元买不到，b2 的 15,000 元已经超过门槛。

样本用满新 X 的 10,000 户，与十五条条款实验是同一名单、同一权重、同一展示顺序。买不到的是 b1 与 b2，共 5,600 户；买得到的是 b3–b5，共 4,400 户。

第一拍不重新调用模型。六项概率和最高选项直接读取已完成的新 X 第 4、6、8 题逐户结果。新跑的只有第二拍：10,000 户 × 3 题 × 4 模型 = 120,000 次调用。

## 二 样本和第一拍来源

画像、抽样权重、展示顺序用 `10000户样本_20261022`。闲置资金用新 X，不用样本文件里的旧 `assigned_idle_X_cny`。展示顺序在该户的第一拍和第二拍中不变，结果映射回 A–F。权重用该户的 `normalized_weight`。

第一拍文件是各模型新 X 结果里的 `c04.jsonl`、`c06.jsonl`、`c08.jsonl`，分别对应 #4、#6、#8。每题 10,000 行，状态均为 ok。最高选项用已保存的 `option_id`。并列在原结果里已经解开；本实验不再改判。

## 三 第二拍怎么生成

三条条款分开。第二拍的人物、收支、已知条款和六个产品文字与该户第一拍相同。只改“当前事件”：保留原句，后面加一句结果。金额写到分。

不开启 Brain 记忆。第二拍仍是一户一次同步 `/v1/systemone`。任务文件由第一拍的最高选项离线生成。模型看不到六项概率，只看到写进状态的那句话。

四个模型沿用已完成实验的调用设置：

| 模型 | 设置 |
| --- | --- |
| sharp-322m | `laya.serve`，`lang=zh`，`max_len=1024`，`head_max_len=256` |
| sharp-421m-mlx | 同上，检查点为已改名的 PyTorch 权重 |
| sharp-4b | 一户一次请求，内部 `max_length=2048`，超长则拒绝 |
| sharp-4b-head-200k | 同上 |

### 3.1 #6 起购 10,000 元

净投入等于 X，申购费为 0。b1、b2 选择 C–F 时买不到；b3–b5 买得到。

| 第一拍最高选项 | 第二拍追加的句子 |
| --- | --- |
| A | 上一轮选择已成交：{X} 元已存入一年期存款，持有至到期。 |
| B | 上一轮选择已成交：{X} 元已买入货币基金，可随时取出。 |
| C–F，且该户属于 b1 或 b2 | 上一轮选择未成交：所选产品净申购金额至少 10,000 元，现有 {X} 元不足，资金未动，目前没有持有该产品。 |
| C–F，且该户属于 b3、b4 或 b5 | 上一轮选择已成交：{X} 元已投入所选产品，申购费 0 元。 |

题目里的金额仍是 X。

### 3.2 #4 申购费 0.5%

净投入 `N = round_half_up(X/1.005, 2)`，费用 `F = X−N`。五档都高于本条 1,000 元起购线，选 C–F 都会成交。

| 资产档 | 户数 | X | 净投入 N | 申购费 F |
| --- | ---: | ---: | ---: | ---: |
| b1 | 3,000 | 1,500 | 1,492.54 | 7.46 |
| b2 | 2,600 | 9,100 | 9,054.73 | 45.27 |
| b3 | 2,400 | 30,000 | 29,850.75 | 149.25 |
| b4 | 1,200 | 53,000 | 52,736.32 | 263.68 |
| b5 | 800 | 88,000 | 87,562.19 | 437.81 |

| 第一拍最高选项 | 第二拍追加的句子 |
| --- | --- |
| A | 上一轮选择已成交：{X} 元已存入一年期存款，未产生申购费。 |
| B | 上一轮选择已成交：{X} 元已买入货币基金，未产生申购费，可随时取出。 |
| C–F | 上一轮选择已成交：申购费 {F} 元已从资金中扣除，净投入 {N} 元已买入所选产品。现在可重新安排的金额是 {N} 元。 |

选了 C–F 的第二拍，题目里的金额从 X 改为 N。产品文字不变。选了 A 或 B 的，题目金额仍是 X。

### 3.3 #8 30 日锁定期

金额不变。本条没有申购费，五档净投入都不低于 1,000 元，选择都会成交。

| 第一拍最高选项 | 第二拍追加的句子 |
| --- | --- |
| A | 上一轮选择已成交：{X} 元已存入一年期存款，未锁定，到期取回本息。 |
| B | 上一轮选择已成交：{X} 元已买入货币基金，未锁定，可随时取出。 |
| C–F | 上一轮选择已成交：{X} 元已投入所选产品。未来 30 日不能赎回，满 30 日后才能免费赎回。 |

题目里的金额仍是 X。

## 四 主结论

每题先算同一户的第二拍减第一拍，再按该户权重平均。区间用家庭聚类 bootstrap，B=1,000，种子 `20261021`。同一户的两拍绑在一起抽。四个模型分开下结论。

主表是 `两拍变化.csv`。每题都报告全体 10,000 户、买不到的 5,600 户（b1 与 b2）、买得到的 4,400 户（b3–b5）。估计值带 95% 区间。

预先写定的主结论：

| 题 | 看谁 | 判定 |
| --- | --- | --- |
| #6 | b1 与 b2，5,600 户 | `p_C+p_D+p_E+p_F` 下降，95% 区间不跨 0；第二拍该概率的水平低于 0.20。两条同时报告 |
| #6 | b3–b5，4,400 户 | 纯债及 ETF 概率的变动小于 b1、b2 的下降幅度。这组买得到，用来区分“多了一句结果”和“结果写明买不到” |
| #8 | 全体 10,000 户 | 权益 ETF 概率下降，存款概率上升，两个区间都不跨 0 |
| #4 | 全体 10,000 户 | 存款概率上升，权益 ETF 概率下降，两个区间都不跨 0 |
| #4 | b1 与 b5 分开 | 分别报告存款变化。b1 的申购费是 7.46 元，b5 是 437.81 元 |

购买未达成仍按新 X 口径：b1 和 b2 在 #6 选择 C–F 时，可执行权益 ETF 金额记 0。原始六项概率照常保存。不在打分前删除选项，也不把概率置零。

另外记录，不写入主结论：第一拍最高选项恰好是该户展示顺序第一位的家庭里，第二拍有多少户的最高选项仍是同一个产品编号。

## 五 保存什么

每个模型一个目录：

- `tick1/`：从第二节的已有文件取出 `c04.jsonl`、`c06.jsonl`、`c08.jsonl`，不重新打分
- `tick2/c04.jsonl`、`c06.jsonl`、`c08.jsonl`：本实验新跑的第二拍
- `表/两拍变化.csv`：主表
- `运行记录.json`：第二拍的通道耗时和成功条数

第二拍每行保留六项概率、最高选项、状态、请求模型、输入全文、展示顺序、资产档、权重、第一拍最高选项、写进状态的那句话，以及第二拍使用的金额。

十五条条款的基准选择、条款影响和人群差异不在本实验里重算，继续用已经完成的八组无记忆结果。

## 六 和后续训练的关系

四个模型分别按第四节判定。第 6 题里买不到的家庭，第二拍水平仍高于 0.20，就说明把成交结果写进状态还不够。下一步才是成对数字监督。不把第二拍的结果写进其余十二条条款，也不把十五条无记忆比较改成带结果回写的比较。
